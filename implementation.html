Common work

  • Drafting or updating policies your board adopts
  • Building a program budget and an organization budget
  • Setting up a simple way to track and report program results
  • Organizing the documents funders ask for into one library
  • Writing an organization profile with text you can reuse in applications
  • Setting up a funder calendar with clear roles

How it works

  1. You choose which fixes to start with.
  2. We agree on scope, price, and dates in writing.
  3. We meet for 30 minutes each week and build the work in shared folders. Projects run 2 to 10 weeks, depending on how many fixes you choose.
  4. You approve each finished item, and we close with a handoff session.
